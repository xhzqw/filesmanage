# G2 第六批 · 万级目录真实浏览器与深链接正确性验收（2026-10-11）

## 发现并修复的产品缺陷

`GET /api/folders/tree` 的兼容读取在 PostgreSQL 仓储中最多返回 500 条授权目录提示。`FolderTree` 已支持按需分页，但 `Documents` 页面仍以这 500 条目录推算 URL `?folder=...` 的选中目录。对于目录搜索结果或书签中的第 501 条及后续目录，页面会错误回落到根目录，显示完全不同的文件集合；这是数据指向错误，不只是慢。

- 新增 `GET /api/folders/:id`，以服务端 `activeFolder` 和 `requireListable` 校验具体目录的权限；缺失、已删除、无权查看均返回不可区分的 404，不泄露隐藏目录信息。调用方不会获得目录正文以外的资源权限。
- 文件工作台对显式的 URL `folder` 使用精确受权查询，未取得结果时展示“正在核验所选目录”，不可访问则显示明确的失败状态及返回入口；不再偷偷回落根目录。没有显式参数的 `/doc` 保持默认根目录行为。
- 将工作台目录根节点判断改为 `Map` 索引，避免兼容目录提示增多时对每个目录反复 `some` 扫描的 O(n²) 代价。
- 新增 Go 授权合同测试，覆盖管理员直接访问、无权/不存在、仅子目录被授权时不能探测隐藏祖先。更新 `gen_openapi.py` 与远端生成的 `docs/openapi-implemented.yaml`。

## 真实目录规模和 Chrome 验证

仅使用受保护的独立 `filesmanage_perf` 及其验证过进程归属的 `127.0.0.1:18094`。只对性能管理员做一次测试登录；目录读取、搜索、展开、分页和滚动操作均只读，没有新建、删除或修改任何业务记录。

数据分布审计：**12/12 PASS**，包括 10,001 个目录、100,466 个文件、402,638 个版本、21 层深度、5,063 个热点目录文件。浏览器使用 Chrome/146.0.7680.177，脚本 `scripts/perf_large_tree_browser_check.mjs`。

| 390px 进入该目录 | 838ms |
