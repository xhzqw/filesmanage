# DESKTOP-INTERACTION-v1 — 桌面资源管理器交互合同

> 项目 filesmanage v2.1 · 版本 1.0.0-draft · 2026-10-09 · 状态：待审定 / 尚未实施
>
> 用户已确认桌面范式：**主文件列表单击选中、双击打开；目录导航树单击导航；目标目录选择器单击选目标**。本文是可实现与可自动化验证的行为规范，不代表现有页面具备该能力。

## 1. 交互域与术语
- `FileExplorer`：主文件列表，可能展示当前目录内的文件；本期不将子目录混入文件表，左树负责目录导航。若后续要混合列表，先新增 ADR。
- `NavigationTree`：主窗口左侧目录树，负责导航，不承担批量文件操作选择集。
- `FolderPicker`：移动/恢复/上传的目标目录选择器，单目标选择，不直接提交移动。
- `Inspector`：当前选择集或单资源详情，与文件打开行为独立。
- `Operation`：有权威服务端结果的创建、重命名、移动、删除、锁、审批和恢复动作。

### 1.1 选择状态最小数据模型
```ts
interface ExplorerSelection {
  folderId: string;
  focusedId: string | null;
  anchorId: string | null;
  selectedIds: ReadonlySet<string>;
  contextTarget: {kind: 'selection'; ids: readonly string[]}
               | {kind: 'file'; id: string}
               | null;
  selectionScope: 'loaded-page';
  orderRevision: string; // 当前目录/排序/过滤/游标代数
}
```
- `selectedIds` 不与 `focusedId` 合并。焦点为键盘目标；选择集为业务影响集合。
- `anchorId` 是 Shift 范围选择起点，由最新非范围选择动作改变。
- `contextTarget` 仅在上下文菜单打开期间存在，不能作为永久业务状态。
- `orderRevision` 在目录、排序或筛选条件切换时变化；异步旧回包不得复活失效锚点。
- 组件卸载/页切换、权限撤回时清理敏感选择状态；不能将不该见的资源元信息继续展示在 Inspector。

### 1.2 数据集与跨页语义（首期冻结）
- 文件 API 默认 50 条，后端上限 200，排序是服务端稳定游标。
- `Ctrl/Cmd+A` 仅选择**当前已加载页面/可见结果**。此合同中“页面”= 一次当前视图可见并已加载的资源集合；如果“加载更多”把第二页追加到 DOM，UI 必须明确标记当前选择范围。建议首期仅在当前 50 项页面生效并用文案说明，避免隐式选择 100k 文件。
- 切目录、改排序、改筛选：清空选择集、锚点和焦点，然后按容器焦点规则定位第一个可见行；不要将选择映射到另一个排序位置。
- 同目录刷新：保留仍授权且仍可见的稳定 ID 选择；被删/失权 ID 立即移除，数量重新计算。缺失锚点时设置 `anchorId=null`。
- 跨页批量及“选择全部 N 项”：不在首期；未来需服务端查询范围签名/授权检查，不传十万 ID 到客户端。

## 2. 三个区域的指针/键盘语义
| 事件 | FileExplorer | NavigationTree | FolderPicker |
|---|---|---|---|
| 左键单击行文字/空白 | 单选并聚焦 | 切换目录（仅激活对象） | 选为候选目标 |
| 双击 | 打开文件预览 | 与单击相同，不触发第二次导航副作用 | 不提交任何移动 |
| 单击折叠箭头 | 不适用 | 展开/折叠，不导航 | 展开/折叠，不提交 |
| Ctrl/Cmd+单击 | 非连续选/反选 | 不作跨目录多选 | 不作多目标选择 |
| Shift+单击 | 选择锚点到目标的当前可见顺序 | 不启用多选 | 不启用多选 |
| 右键已选行 | 保持现有多选并打开当前选择集菜单 | 打开被点击目录的安全菜单 | 仅可显示选择器允许的帮助/路径项 |
| 右键未选行 | 先单选被点击行再打开菜单 | 右键对象为该节点 | 仅可设为候选，不移动 |
| 左键点击列表空白 | 清空选择（焦点留在容器） | 不适用 | 清空候选（若目标流程允许） |
| Enter | 打开焦点文件；单选条件下可选中后打开 | 导航到焦点目录 | 选择焦点候选/展开，不提交事务 |
| Escape | 关闭顶层 UI→退出重命名→清选择（优先级见 §4） | 关闭菜单或退出编辑 | 关闭菜单；若无菜单则取消选择器 |

**特别约束**：按钮、下载链接、输入框、checkbox 内部 click 不得向行选择误冒泡，除非交互合同明确该行为；在触屏环境不依赖双击，提供明确“打开”动作。

## 3. FileExplorer 选择状态机
### 3.1 输入事件→状态转移
| 前态 | 输入 | 后态 | 激活/副作用 |
|---|---|---|---|
| 空选择 | 单击 A | `{A}`，focus=A，anchor=A | 不打开 |
| `{A}` | 单击 B | `{B}`，focus=B，anchor=B | 不打开 |
| `{A,B}` | Ctrl/Cmd 单击 C | `{A,B,C}`，focus=C，anchor=C | 不打开 |
| `{A,B,C}` | Ctrl/Cmd 单击 B | `{A,C}`，focus=B，anchor=B | 不打开 |
| anchor=A | Shift 单击 D | 选择 `[A,D]` 的**当前可见排序范围**，focus=D，anchor=A | 不打开 |
| anchor=A | Ctrl/Cmd+Shift 单击 D | 原选择并集范围 `[A,D]`，focus=D，anchor=A | 不打开 |
| `{A,C}` | 右键 C | `{A,C}`，contextTarget=selection | 多项菜单 |
| `{A,C}` | 右键 D | `{D}`，focus=D，anchor=D，contextTarget=file(D) | 单项菜单 |
| 任意 | 双击 D | 不批量激活其他项；`D` 打开 | 导航到 `/preview/:id`；原状态按路由恢复策略清理 |
| 任意 | 点击列表空白 | 空选择，anchor=null | Inspector 隐藏选择详情 |
| `{A,C}` | A 已失权/删除 | `{C}`，若 anchor=A→null | 不允许使用陈旧权限 |

### 3.2 点击/双击竞争
- 主表统一通过 React 组件定义双击激活。第一次 click 的单选效果可以短暂出现，但在双击打开前**不得进行任何不可逆业务动作**。
- `click` 事件只改本地选择，不触发预览；`dblclick` 才路由跳转。双击行内操作按钮需排除。
- 文件名视觉可以像可操作资源，但不能有默认单击导航的 `<a>` 行为；如提供独立“打开”链接，应明确该区域为显式链接且遵守事件约束。
- 移动设备、辅助技术可通过 toolbar/menu 的“打开”替代双击。

### 3.3 焦点键盘交互
- 当列表容器激活时：`ArrowUp/Down` 移动焦点到上一/下一**可见**文件；不修饰时建议焦点同步为单选；`Ctrl/Cmd+Arrow` 移动焦点但保持选择集；`Shift+Arrow` 扩展锚点范围。
- `Home/End` 到本加载范围首/尾；`PageUp/Down` 根据可视高度跳转焦点（虚拟化实现必须保持视觉焦点）。
- `Space` 选择/反选当前焦点项；`Enter` 打开；`F2` 单选时开始重命名；`Delete` 对选择集发起删除确认；`Ctrl/Cmd+A` 选择当前页面。
- `Shift+F10` / 专用 Menu 键打开焦点资源菜单；Menu 关闭后把焦点还给来源资源。
- `Tab` 只在主要交互区进出，不要求逐行逐格 Tab；如采用 `role=grid`，必须真正实现 ARIA Grid 的内部 roving tabindex/aria-activedescendant。
- Shift 范围使用可见顺序 ID 数组，不能使用 DOM 兄弟序号和“已渲染节点”猜测；虚拟化需维持滚动定位。

## 4. 快捷键作用域及优先级
```
focused text input / contenteditable / ONLYOFFICE / CAD viewer
  > AlertDialog & Dialog
  > Menu / Popover / ComboBox
  > 当前工作区 FileExplorer / Tree
  > Global AppShell
  > browser default
```
- `Ctrl/Cmd+A` 在输入框必须选择文字；`Backspace` 在可编辑控件删除字符，不触发目录后退或文件删除。
- `Delete` 在选择器/输入框和 CAD 模型内部不得被 FileExplorer 全局监听器抢走。
- `Escape` 始终只撤销**最上层可撤销交互**。不可取消的提交过程只能显示进度与继续，不允许丢失服务器操作状态。
- 不覆盖浏览器地址栏、刷新、开发者工具等默认快捷键；`Ctrl+C/X/V` 文件复制/剪切未立项，不做假实现。
- macOS 使用 Meta/Cmd；Windows/Linux 使用 Control。每个 action 需要无鼠标入口和可读取的快捷键描述。

### 4.1 弹窗与焦点合同
1. 打开 Dialog：保存 trigger 元素；把焦点移入标题/首个可用表单；启用背景 inert 和滚动策略。
2. 按 Tab/Shift+Tab：焦点在真模态对话框可操作元素中循环。
3. Escape/取消：如果没有事务提交且未阻止关闭，安全关闭；有脏编辑内容时先确认放弃。
4. 提交：立即 busy+禁用重复提交；等待真实服务端结果才显示成功；成功关闭并恢复焦点。
5. 关闭：如果原 trigger 不存在，则回到最近的工作区安全焦点（例如表格容器），不丢键盘能力。
6. 不再将 `<dialog open>` 视为符合模态要求；使用已审查的 Dialog 原语和真实模态能力。

## 5. NavigationTree 合同
- 每行有展开按钮与激活区域；**单击节点名称导航**、单击 chevron 仅展开/折叠。不能让“展开”同时触发目录切换。
- `Up/Down` 在所有**可见**节点间移动焦点；`Right` 展开已折叠父项/进入首子项；`Left` 折叠已展开父项/跳父项；`Home/End` 定位首/末可见节点；`Enter` 激活当前焦点目录。
- 焦点、展开态、当前激活目录独立；节点使用 `aria-expanded`、`aria-current` 或适当的 `aria-selected`，不能混用含义。
- 目录不一定从全局根可见：如果因权限裁剪而看不到祖先，授权可见的子目录应显示为可访问根，不得泄露隐藏祖先。
- 用 parentId→children index 构建可见子树；10k 目录采用 API 分段获取/窗口化加载，不在 render 中对子数组反复 `.filter()`。
- 目录异步展开必须区分 loading/empty/error，失败能在原节点重试；高速切换目录时旧请求必须被取消或按 generation 忽略。

## 6. FolderPicker 合同
- 仅选择一个目标文件夹；与主导航共享基础 Tree 原语，但**不共享资源打开和多选语义**。
- 首次打开显示当前候选路径；可以按目录名与可见路径搜索（仅返回授权可见信息）；最近使用和收藏为可选增强。
- `selectedTargetId`、`validationGeneration`、`validationState`、`conflicts[]`、`impactSummary` 是核心状态；同一预检代数只能对应一个候选目标和来源集合。
- 选择新目标时：使先前预检结果立即失效，取消旧请求/忽略旧响应，提交按钮重新禁用直至重新验证。
- 非法目标：自身、自身后代、已删除、用户无目标上传权限、跨安全边界策略不允许。明确给出可披露的原因，不展示未授权路径。
- 点击 “检查并继续” 启动服务端预检；确认页显示原目录、目标目录、资源数量、潜在 ACL 继承变化与冲突。预检通过也不等于授权，**commit 事务内再检**。
- Enter 在 Tree 内只选目标或展开；不会悄悄执行移动。提交按钮获得焦点时 Enter 才按明确按钮行为提交。
- Esc 清理当前候选与验证请求并关闭；commit 若已受理须等待结果或显示可查询的操作状态，不称“已取消”。

## 7. 拖放会话
### 7.1 外部文件→上传
- 将 OS 文件拖入文件列表/目录目标，作用是上传，不是打开新页面；仅在明确可写目标时接受。
- DragEnter/Leave 高亮目标；Drop 生成上传队列项；列表必须存在非拖放的文件选择入口。
- 不能把文件拖放到正在编辑的文本输入区误触发全局上传；默认阻止浏览器导航只在正确的 drop-zone 范围内实施。

### 7.2 内部文件/目录→移动
- 拖动来源必须是可操作的选择集；拖到文件夹时显示合法/非法目标，长列表自动滚动，悬停展开为可选增强。
- `dragstart` 仅创建 `DragSession`：来源集合、来源目录、原焦点、是否合法；**不写服务器**。
- `drop` 触发目标验证，必要时展示影响确认；禁止因为 HTML DragEvent 触发了 drop 就直接越过服务端校验。
- Escape、拖回来源、drop 到非法区域：取消拖放且服务器无变化。
- 使用“移动到…”菜单可完成同等操作，不把拖放作为唯一入口。
- 操作系统修饰键暗示复制的行为本期不提供；不得显示“复制”光标而实际执行移动。

## 8. 资源操作门禁
- `ActionAvailability` 输入：当前用户可获知的权限事实、选择 ID 集、资源状态（锁/审批/失效）、操作类型；输出 `enabled/disabledReason/requiresConfirmation`。
- 前端 capability 只用于可用性提示，绝不是授权证据；每次写入在后端重检权限与当前版本/锁。
- 右键多选显示**全部选中资源共同可执行的动作**；若混合权限可禁用并解释，不偷偷跳过。
- 删除目录显示子树影响数量与无法预知的部分，回收站语义明确；永久删除须额外醒目的不可逆确认。
- 成功但刷新失败：分别反馈“操作已提交 / 列表刷新失败”，不能否定已完成写入或冒称一切同步完成。

## 9. 异步一致性与性能
| 场景 | 规则 |
|---|---|
| 切目录后旧响应回到页面 | 丢弃旧 generation；不得覆盖新目录文件表 |
| 排序/过滤改变 | 清锚点选择；滚动恢复到顶部；旧游标不可复用 |
| `loadMore` 连点 | 请求互斥、游标去重；只按服务端 nextCursor 追加 |
| 移动成功 | 失效来源/目标列表、路径、Inspector、授权派生视图 |
| 修改/保存/审批生效 | 更新最新版本/元数据，版本表与当前表格一致 |
| 授权撤销 | 下次读取不得复用旧授权数据；选择集剔除失权项 |

**候选 UX 延迟预算（非实测结果）**：选择本地反馈 p95 ≤50ms，已可计算的菜单显示 p95 ≤100ms；目录展开必须立即反馈，服务端加载另计；大目录保证无持续主线程长任务。测试需在远端固定浏览器/设备/数据规模下记录 p95，而不能只观察一次点击。

## 10. 具体回归脚本合同
- `DI-01` 单击不打开；双击才导航；含文件名、行空白与操作按钮排除。
- `DI-02` Ctrl/Cmd 切换多选，Shift 选择可见排序范围，修改排序后锚点清理。
- `DI-03` 右键已选资源保留选择；右键未选目标变为单选；键盘菜单等价。
- `DI-04` Tab/Enter/Space/F2/Delete/Escape 在当前作用域执行正确动作。
- `DI-05` 输入框和 DOCX/CAD 不被 Explorer 快捷键拦截。
- `DI-06` 数据刷新、并发切目录、被删资源后选择/焦点保持正确。
- `DI-07` 10k 目录展开/搜索；异步失败重试；授权可见孤立根节点。
- `DI-08` FolderPicker 多次切换目标时旧预检绝不能解锁新目标的确认按钮。
- `DI-09` 拖放外部文件和内部资源区分；非法 drop 不触发业务写入。
- `DI-10` 所有动作必须有非拖放/非双击替代方式。

> 每条验收的样本角色、步骤、断言及证据格式以 `UX-ACCEPTANCE-v1.md` 为准。所有测试只在远端隔离开发数据上执行。
