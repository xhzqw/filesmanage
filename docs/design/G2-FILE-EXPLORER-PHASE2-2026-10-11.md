# G2 文件工作台 · 第二批整改与验收（2026-10-11）

## 范围

第二批围绕文件夹树、目录操作、上传拖放及任务队列，保持现有 React/Go 分层和 Rare UI 语义，不改业务 API、授权判定或文件版本规则。

- **拖拽类型隔离**：`DropZone` 仅拦截浏览器实际的外部文件拖拽。内部文件移动 MIME、选中文本、链接、文本输入框上方的拖拽不触发上传抢占。文件表格向目录树拖放仍必须经过原有移动预检及确认对话框。
- **队列独立区域**：上传队列变成紧凑底部任务栏，支持展开/收起；记录列表有容器级滚动和高度上限，不会随任务数量增多推离文件列表或页面底部操作。对当前面板实际宽度做响应式布局，避免全页横向溢出。
- **保留目标目录**：文件加入上传队列时确定 `targetFolderId`，SPA 导航切换目录不会修改它；非当前目录的任务显示“其他目录”，上传成功只刷新正确目录。
- **目录右键目标生命周期**：从目录树对非当前目录发起重命名/删除后，成功或取消均会释放临时上下文，使顶栏目录操作恢复指向当前目录；删除当前目录或当前目录的祖先时导航到仍然存在的父目录，避免显示已删除路径。
- **错误/危险动作**：重命名、删除失败仍留在对话框并保留错误反馈；本批没有绕过后端权限、删除确认、版本 CAS 或上传任务幂等键。
