# Visual System V3 — 统一几何与视觉层级

状态：IMPLEMENTED（开发环境）。批准依据：2026-10-09 用户明确指出现有 UI 不统一、纯直角不符合预期。

## 1. 对 V2 的覆盖范围

本设计契约仅在**形态 / 圆角 / 视觉容器组合**方面优先于
`PRECISION-WORKBENCH-V2-SPEC.md` 中的「0-gap 方角嵌合」和
`--radius-xs/sm/md = 2/4/6px`。保留已验证的色彩对比、操作语义、
高密度表格（32/26px）、40px 顶栏、28px 目录行、24px 状态栏、
焦点轮廓、业务逻辑和层级导轨。

## 2. Geometry tokens

| Token | Value | Use |
|---|---:|---|
| `--radius-xs` | 4px | 小标签、键位提示、微型控件 |
| `--radius-sm` | 7px | 按钮、输入框、导航项目、树行 |
| `--radius-md` | 11px | 表格面板、媒体舞台、菜单 |
| `--radius-lg` | 15px | 主工作区、侧边栏、业务卡片 |
| `--radius-xl` | 20px | 对话框、登录卡片 |
| `--radius-pill` | 999px | 版本徽章及明确的胶囊标签 |

全站统一从 `web/src/visualSystem.css` 获得最终几何定义，
`web/src/main.tsx` 在 `theme.css` 后加载该样式。组件不得引入任意
3/5/9/13 等独立半径，不得在独立表面使用 `border-radius:0`。
只有完全贴边的内部构造、输入内嵌区域、浏览器原生视频内容可不额外设角，
但其**可见外层必须裁切到所属表面半径**。

## 3. Surface hierarchy

1. 顶栏、侧边栏、主工作区采用 15px 圆角 + 1px 中性边框 + 极轻阴影；
   shell / panels gap = 8px，防止相邻区域形成大面积方直角硬接缝。
2. 内容工具栏、面包屑、表格采用 7/11px 圆角，小间距内嵌；不增加数据行高。
3. 卡片、权限工作台、浮层统一 token 及轻量投影；菜单内部项目采用 7px。
4. 视频、图片、CAD、在线编辑舞台使用 11px 裁切，消除预览独立样式割裂。
5. 小屏把 frame 间距压缩到 5px；禁止以额外边距造成横向溢出。

## 4. 不可回退约束

- 必须保留带键盘焦点的明显 focus 状态，不得用无对比度阴影替代焦点轮廓。
- 新样式不得用全局 `*` 或 `!important` 覆盖业务状态；只在明确定义的
  shell / surface / control 上治理，避免穿透 CAD Canvas 或 Office iframe。
- `Preview` 页面独立滚动，表格和目录树的滚动宿主不得因圆角裁切而变化。
- 视觉验收需要覆盖登录、文档、预览、组织与权限、回收站、弹窗、响应式；
  关注几何 computed styles、选中态、键盘焦点及是否发生横向溢出。
