# 工作台减法整改 / Workbench Focus

本次整改对象仅为工作台。Finder 文档管理、文件夹和文件预览不作任何修改。

## 消除的 UI 冗余

- 左侧默认由二十多个常驻入口缩减为 **我的工作 / 项目 / 知识** 三个。「更多业务」仅保留九个跨流程或治理入口；更细的签收、责任、审批子分类不再单列导航，但原任务上下文操作和历史深链接仍然有效。
- 首页不再出现六块流程入口、四张数据卡、三块右栏卡片、独立审批和 DHF 计数卡的叠加。
- 新首页只保留一份按任务优先级排列的工作清单；审批和 DHF 属于清单中的源队列入口，各自显示真实计数，不将不同业务口径强行相加。
- 我发起的和流转中保留为底部轻量入口，不重复渲染一套信息卡片。
- 新建操作不放多处，只有右上角统一「发起」，其余具体动作仍由原业务工作流执行。

## 权限与兼容性

原文件工作、审批、Gate、项目及知识页面仍使用既有后端授权与组件。仅改变展示密度与导航位置，不改变数据库迁移、项目数据或业务授权。旧 `?view=...` 查询参数和业务路由继续可用。

## 验收要求

1. 静态 Finder 边界与减法交互检查通过。
2. 远端 Go / TypeScript / Vite / RareUI CI 通过。
3. Chromium 实际登录后在 1440/1024/760/390px 浏览；验证三主导航、更多业务展开、旧深链接、审批、Gate、知识及 Finder 不变。
4. 在隔离候选端口复验，再切换开发环境 `10.144.144.1:18091`。若无法访问服务器则不称已部署，生产 `8091` 始终不触碰。
