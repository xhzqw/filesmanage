# G2 文件工作台 · 第三批整改与验收（2026-10-11）

## 本批交付

1. **队列历史治理**：上传成功（committed）和已取消（cancelled）为结束态；显示最近 40 条结束记录，失败、排队、上传中和中断待恢复项不计入上限，且不会自动清除。新增“清除已结束”入口，不影响失败重试和待恢复。
2. **续传缓存时效**：只保存大文件的小型验证元数据（非文件内容）；按加入队列的时间 `cacheAt` 计算 48 小时期限。恢复和进度状态更新不会刷新这个时间，过期缓存不再持久化。
3. **目录树分页**：同一目录下一页请求未结束时不重复触发；合并分页时对 id 去重，保留先出现的目录行及焦点身份；异常重放的同一游标不再无限循环。
4. **构建门禁**：`scripts/ux_upload_queue_logic_check.mjs` 在远端借助 esbuild 内存编译真实 TS 模块，断言历史上限、保留可操作任务、分页结果身份与顺序、缓存时效；集成 `scripts/build.sh`。
5. **浏览器工作流**：在已有的上传、目录切换、文件移动检查中增加任务结束后“一键清除历史”的断言，位置位于 SPA 切换目录之后、完整页面重载之前，避免把小文件非持久历史误判为丢失。
