# Polar Blue · 全局色彩契约 V1.0

## 设计方向
苹果式冷白画布，低噪声界面，深海蓝强调当前操作。保留现有 RareUI
和文件类型图标，不引入另一套组件体系，不改变业务行为与布局密度。

## 主题层级
| 语义 | CSS Token | 浅色主题 |
| --- | --- | --- |
| 应用背景 | `--ui-bg-app` | `#F7F9FC` |
| Finder 侧栏 | `--ui-bg-sidebar` | `#F4F7FA` |
| 内容画布 | `--ui-bg-canvas` | `#FFFFFF` |
| 静态细分隔线 | `--ui-border-hairline` | `#E5EAF1` |
| 悬停 | `--ui-state-hover` | `#EDF2F8` |
| 侧栏选中 | `--ui-state-selected-sidebar` | `#DFEBFA` |
| 网格卡片选中 | `--ui-state-selected-grid` | `#D7E8FC` |
| 列表／分栏强选中 | `--ui-state-selected-list` | `#2459B2` |
| 键盘焦点 | `--ui-state-focus` | `#2459B2` |
| 主品牌色 | `--ui-brand-primary` | `#2459B2` |
| 深海蓝 | `--ui-brand-strong` | `#193F81` |
| 主要文字 | `--ui-text-primary` | `#1D2A3D` |
| 次级文字 | `--ui-text-secondary` | `#5E6F85` |

七色分类标签仅使用 `--ui-tag-red/orange/yellow/green/blue/purple/gray`；
组件的标签圆点、菜单色板与文件卡片必须读取同一变量，避免颜色漂移。
标签色不得承担选中／危险／成功等系统状态。

## 使用规范
- 导航仅高亮当前路由，其他位置应采用中性色。
- 网格选中采用一层蓝色边界和浅蓝填充；焦点轮廓只在 `:focus-visible` 绘制。
- 列表、分栏维持深蓝强选中，并确保白色文字清晰。
- 悬停采用轻灰蓝，不额外叠加强蓝边框。
- 不通过全局 CSS 改写 PDF、Office、CAD、视频或用户图片内容。
- 低频按钮保持中性，主要操作采用品牌蓝，危险操作使用独立语义色。
- 仅必要结构绘制线条，不为装饰增加多重卡片、边框及重复标题。

## 兼容与落地
现有 `--brand-*`、`--surface-*`、`--color-*` 等变量保留作为语义别名，
避免旧模块失效。新建或重构组件引用 `--ui-*`。
交互边界不得直接使用浅灰色 hairline 代替需要 >=3:1 对比度的边框。

## 验收
所有构建、测试、浏览器尺寸回归与服务启动均仅在远端进行。
至少在 1366×768、1440×900、1920×1080 观察文档管理工作台，
并复核搜索、预览、审批、统计、标签拖拽、单选／多选及键盘焦点。
普通文本 >=4.5:1；重要非文本交互边界 >=3:1。
