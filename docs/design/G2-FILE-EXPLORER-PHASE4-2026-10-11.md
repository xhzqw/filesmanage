# G2 文件工作台 · 第四批验收记录（2026-10-11）

## 本批范围

聚焦文件预览、文件列表和回收站之间的**陈旧视图状态**。服务端是事实来源，浏览器端变更通知只用于失效提醒，不复制权限、文件内容或业务状态。保留 Rare UI 低噪声、紧凑布局。

- **预览重新校验**：文件预览在浏览器窗口返回前台时重新读取预览、文件元数据和版本；异步请求有 React effect 生命周期守卫，切换 fileId 或连续刷新后旧请求不能覆盖新页面。开始重新校验时清空旧 preview/file/version 数据，失败时不再保留旧版本/下载/删除操作。
- **恢复路径**：预览文件不可访问或已删除时，提供紧凑“重新加载 / 返回文件列表 / 查看回收站”，不声称删除一定是唯一原因。
- **跨标签变更提示**：文件写入、重命名、移动、删除、回滚、生命周期/元数据更新，以及文件夹和回收站恢复/永久删除后，将最小资源失效 token 写入同源 localStorage；其他标签页由 storage 事件唤起服务端重新校验。当前标签页继续使用原业务成功回调，不在保存/回滚对话框中间强制卸载。
- **文件列表与回收站刷新**：监听对应资源失效事件和页面返回前台；回收站原有分页在尾页因外部删除而变空时退回上一有效页，避免卡在空的高页码。
- **校验合同测试**：新增 `scripts/ux_resource_sync_logic_check.mjs` 并挂到远端 `scripts/build.sh`；检测跨标签 token、当前标签保存安全、失效消息校验、监听生命周期、focus/visibility 事件合并。

## 已知边界和后续

- **没有开展 10k 目录/100k 文件压测**；上批小规模性能结果不等于真实容量验收。
- 文件变更通知仅同源多标签；其他设备/服务器端操作靠回到前台时重新请求，不承诺实时 WebSocket 推送。
- 断点上传的服务端会话对账、网络断开后重新连接及冲突多端恢复矩阵尚未全面覆盖，继续作为下阶段专项。
- 预览和回收站不会未经用户动作自行恢复或删除业务数据；变更 token 不包含文件正文。
