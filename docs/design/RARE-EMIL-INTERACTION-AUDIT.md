# RareUI × Emil Skills — 第一轮审计与验收合同

基线：2026-10-12，基于远端 `origin/main` 的 `1121121`，与并行工作的其他 Agent 隔离。

## 技术策略

RareUI 仍是唯一视觉体系。Emil Kowalski 的设计工程 Skills 用于代码/交互审查，不作为生产前端依赖。现有项目已经依赖 `motion` 和 Zustand，不引入第二套通知/动画组件。

推荐审查组合：`emil-design-eng`（核心观感）、`break-ui`（极端数据）、`review-animations`（严格审查）、`animation-performance`（帧性能）以及 `animate`（必要动效实现）。

## 第一批已编码的增量

- 统一内部拖拽的 `text/plain` 回退与文件名拖影语义。
- 在 `AGENTS.md` 固定 RareUI × Emil Skills 审查方法、禁止重复组件、动效/低噪声/异常数据的边界。
- 以 `scripts/rare_emil_interaction_check.mjs` 监控现有实现，接入远端构建门禁，防止未来 Agent 重新引入整行拖影、多余选中线或无暂停 Toast。

## 待执行的远端浏览器验收

1. 1440px、1280px、390px：文件表格长名称（中英文）、多选、行键盘焦点以及 Toast 上中位置。
2. 内部拖到合法目录 / 同源目录 / 无权限目录，按 Escape 取消；外部文件拖入不得混淆成内部移动。
3. 成功、错误、loading、并发操作、Modal 内通知；Hover/焦点/切后台后剩余时长行为。
4. 预览页 PDF、图片、视频、文本、大文件名，确认右侧主体优先、左侧功能区不产生页面级水平滚动。
5. 空目标目录、不同目录存在同名文件、目标确有同名文件、没有权限四个移动预检场景，必须记录服务器实际返回值与界面反馈。

未走完上述真实浏览器/业务测试的内容只能记为待验收，不能宣称部署或已完全修复。
