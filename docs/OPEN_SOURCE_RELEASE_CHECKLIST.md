# filesmanage 公开开源发布检查清单

状态：**待审查，禁止直接公开当前工作仓库及其历史**（2026-10-13）。本清单不等同于已经获得第三方授权或法律意见。

## 第一方代码与许可证

- [ ] 确认所有第一方代码的实际著作权归属及贡献者授权，批准采用根目录 `LICENSE`（AGPL-3.0-only）。
- [ ] 从待发布代码和 Git 历史核实无明文密码、令牌、密钥、证书私钥、真实用户信息、签名、公章或敏感文档；如曾泄露，先吊销并轮换，不仅是删除最新文件。
- [ ] 为公开使用者提供通用配置模板和从零部署说明，不依赖内部 `.secrets/`、固定内网 IP、SSH 别名、绝对路径或内部管理员账号。
- [ ] 审阅文档中的企业名称、内部地址、域名、拓扑、日志、压测结果、客户交付记录等，分离公开开发者文档与内部运维材料。

## 第三方依赖与版权

- [ ] 将自托管 ONLYOFFICE Docs 作为独立服务部署；遵守其带附加条款的 AGPLv3，保留法律声明，不移除原有归属信息或冒用商标。
- [ ] 审计 `web/src/` 中来源于 Rare UI 的组件及复制代码，审查 MIT + Commons Clause + 署名条件；无法确认兼容公开分发则更换实现或取得额外许可。
- [ ] 完成前后端直接和传递依赖、字体、图标、图片、加载动画、CAD 转换工具等的许可证/SBOM 清单；第三方材料按各自许可证发布。
- [ ] 确认 `web/public/assets/brand/`、签章/签名模板、测试样本、设备图片及其他公司专属资产有公开授权；否则改为中性占位素材并彻底清除待发布历史中的原文件。

## 发布与功能验收

- [ ] 在**独立的公开仓库或已清理的历史**上预览发布内容，使用秘密扫描器、路径/版权审计及人工审查。禁止直接将当前内部仓库设为 public。
- [ ] 在授权的测试环境验证 DOCX 双击预览不触发下载、ONLYOFFICE 编辑器加载、JWT 鉴权、保存回调、权限拒绝、历史版本及回滚；同时验证断网/回调失败不会误显示已保存。
- [ ] 审核公开部署的默认安全配置：JWT 密钥来自环境/密钥管理、不启用开发默认值；ONLYOFFICE 文档源和回调 URL 可达且具有访问边界，禁止由用户输入任意内部 URL。
- [ ] 经负责人对许可证、素材及秘密扫描结果签收后，再执行公开仓库发布操作。
