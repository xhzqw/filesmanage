## 3. 工程保障（摘要）

- **架构**：71 个 Go 文件 / 41 个 TS 模块的分层依赖由自动门禁强制（负向规则自测）。
- **契约**：66 个端点全部进入 OpenAPI 契约（50 路径 / 46 schema），改路由不重新生成
  即构建失败；126 个 SPEC 验收 ID 逐条可追溯（123 PASS / 2 PARTIAL / 1 EXTERNAL）。
- **一致性**：blob 暂存→提交→发布协议 + 崩溃恢复清扫（AG09 演练 4/4）；备份恢复演练
  通过（26 表 / 384 blob）。
- **稳定性**：10 分钟持续负载 108,684 次请求零 5xx，文件描述符恒定（无泄漏）。
- **可回溯**：升级/回退演练 12/12（含跨格式回退：新构建写入的数据在旧构建下字节级存活）。
- **数据隔离**：旧 Node/SQLite 系统与数据完整未动（DEC-15 全程遵守）。
